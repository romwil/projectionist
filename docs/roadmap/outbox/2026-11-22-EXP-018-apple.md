# Handoff: warm-up lines and playback steps

**Server item:** EXP-018
**Status:** accepted, not started. The lines file and the step names ship before any client screen. Not a release.
**Capability (proposed):** `warmup_screen` is `1` on `GET /api/features` when the lines document and the session `step` are served. A missing name means the client shows the title's art and an honest status line, and does not show a joke line.

This handoff is the platform contract. Client screens and layouts stay in the client repository. The starter lines live in the accepted drop [2026-11-22-EXP-018-warmup-screen.md](../accepted/2026-11-22-EXP-018-warmup-screen.md) and ship in the server file so every client shows the same lines without a client release.

## Routes (proposed)

- `GET /api/playback/warmup-lines` returns a versioned document: a general pool, plus a pool per step. Clients cache it.
- `GET /api/playback/sessions/{session_id}` gains `step`, one of `waking_disk`, `probing`, `remuxing`, `encoding_audio`, `preparing_captions`, `falling_back`, `waiting_on_plex`, `buffering`.

These routes and fields are not on the server yet.

## What the client renders

- One line at a time from the current step's pool, then the general pool. No line repeats during the session. An error is never a joke.
- Under it, a short honest status line with a counter of how long this start has taken. That line is the live region. Joke lines are decorative.
- The screen ends on the first frame.
- When the first-frame fallback moves to the library path, the screen stays up and uses the `falling_back` pool. The member does not see a failure for a fallback that works.
- After about 45 seconds with no first frame, the jokes stop. A plain message offers keep waiting, try again, and back, with the reason.
- The owner setting is Warm-up humor: On (default), Dry (status line only, art kept), or Off (a minimal indicator on the art). Lines stay appropriate for every member, including Youth.
- Reduced motion: no drift and no flicker. Lines may still change.
- On Live, the existing static stays a short channel flip. If the tune takes longer than about 1.5 seconds, the static gives way to this screen, using the program's or the channel's art. This is not a new channel type.

## Done when the client ships

A cold start shows the lines for the real step, the honest status, and the counter. A forced fallback changes lines without an error. The 45-second choice appears. Reduced motion and the status-only live region hold.

EXP-018 on a released server. The session `state` values from the work already running. Art URLs from EXP-006.
