**Date:** 2026-11-23 · **Server item:** TML-002 · **Capability:** `timeline_dialogue` 1

Depends on `timeline_files` 1.

## What changed

`POST /api/library/timeline/files/{id}/dialogue` reads the household subtitle cache for that file's title and stores one dialogue event per cue. The response is the count, the language, and the file id. It does not return the lines. A later import replaces the previous dialogue for that file.
