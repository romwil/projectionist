# Handoff: rooms

**Date:** 2026-11-21 · **Server item:** SES-002 · **Capability:** `rooms` 1

## What changed

`GET /api/rooms` returns the household's named screens for any signed-in member:

```json
{ "rooms": [{ "id": "…", "name": "Living Room", "kind": "tv" }] }
```

A handheld is not a room. A removed screen is not a room. The list does not include what is playing, and it does not include who is signed in on the screen.

`PATCH /api/rooms/{id}` with `{"name": "Den"}` renames a room. The household owner may rename any room. The member signed in on that screen may rename it. Anyone else gets 403. An unknown room is 404.

## What the client does

- Read the list when `rooms` is at least 1.
- Show the names. Do not infer what is playing from this response.
- Send a rename only for a screen this member may name.

## Done when (client)

- A signed-in client can list the household's screens by name.
- A signed-out client is not shown the list.
