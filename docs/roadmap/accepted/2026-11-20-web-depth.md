# Drop: web depth pass — posters with light, generated placeholders, glass nav

**From:** design chat · **Date:** 2026-11-20 · **Roadmap:** new EXP item (next free number), alongside EXP-004/005/006
**Reference:** design canvas board `WebExplore` and the yellow "Depth pass" sticky.

## Why

Reviewers find the posters flat. The web should match the native clients' depth: art with light and an edge, and a lift on hover and focus.

## Decisions (accepted)

1. **One `Poster` component** for every shelf and lockup:
   - rounded 12 px, `overflow: hidden`;
   - rim light: `inset 0 1px 0 rgba(255,255,255,.30), inset 0 0 0 1px rgba(255,255,255,.08)`;
   - two-layer shadow;
   - bottom scrim when the title is drawn on the art.
2. **Lift on `:hover` (pointer devices only, `@media (hover: hover)`) and on `:focus-visible`:**
   - `translateY(-4px) scale(1.04)`, a deeper shadow and a diagonal specular sheen, 180 ms ease-out;
   - no lift under `prefers-reduced-motion` (shadow change only).
3. **Generated placeholders, never a flat tone.** When art is missing or loading:
   - render a deterministic placeholder seeded by the item id: duotone gradient, one radial light, a CSS `clip-path` silhouette (skyline / road / tower / hills / dunes), the scrim, and a title + year lockup;
   - cached art from `/api/library/art/...` fades in over it.

   The same seed rules as the Apple client, so a title looks alike everywhere.
4. **Hero:** full-bleed layered art with a reading-side scrim. No boxed blocks.
5. **Top nav:** a glass capsule using `backdrop-filter: blur(30px) saturate(1.6)`, with a translucent fill and a solid fallback via `@supports not (backdrop-filter: blur(1px))` and under `prefers-reduced-transparency`. Reading text never sits on glass.

## Done when

- Explore, Title and Live shelves use `Poster`, and no flat-fill placeholders remain.
- Keyboard focus shows the lift and a visible focus ring.
- Screenshots at 390, 834 and 1440 px sit next to the canvas board.
