### Roles and permission model

| Role | How it exists | What it can do |
|---|---|---|
| Implicit owner | `multi_user_enabled=false` (default) | Entire app, no login |
| `owner` | Multi-user on | Admin, *arr writes, MCP keys, users, Live craft |
| `member` | Multi-user on | Chat/Explore/Play/Live/Inbox/settings; Seerr request path when enabled; no Admin |
| Youth | `users.is_youth` flag on a member/owner row — **not** a third role enum | Rating gate, nav labels Ask/Browse, SDH captions preference, blocked playback |
| Guest-tour | Flag `guest_tour_enabled` | Historical public `/tour`; current routes send `/tour` → `/login` |

Join is invite-only by default (`invite_only=true`). Access-request queue is a novice toggle. `open_auto_provision` is opt-in LAN-open (env-gated).

Agent personal mutations are gated when multi-user is on unless `agent_may_mutate_personal_data` (`ToolRegistry._deny_personal_mutation_if_gated`).

## 3. Sacred cows register (initial)

1. **Chat is the primary product**, not Explore/Play/Live.
2. **Library-grounded recommendations** — never a Netflix-style catalog that ignores ownership.
3. **Taste must not be one blended profile** — lenses / named kinship / For you named links.
4. **Confirm before *arr/Seerr writes** — no silent grabs.
5. **BYO LLM, zero telemetry SaaS** — local-first, AGPL, no Projectionist cloud.
6. **Single container + SQLite** — no Postgres/Redis for 2–3 years (`docs/PRODUCT.md` parked).
7. **Plex-first** — Jellyfin/Emby are non-goals.
8. **Multi-user is opt-in**; default is trusted-LAN single owner.
9. **Youth is a flag, not a role.**
10. **Native Live without Tunarr** (1.37.51+); do not resurrect HDHomeRun/Tunarr orchestration.
11. **Lobby Theater is a LAN kiosk**, not the member app.
12. **Lights Down cinema + amber + Fraunces** as brand.
13. **Hub-first ship**; host `docker build` is not CA proof.
14. **Cookie/DB names keep `curatorx_*` twins.**
15. **MCP dual keys** (privacy vs full) as the agent interface.
16. **For you must never fill with cosine** when a named plot link is missing.
17. **Owner Monday pass** as the stewardship ritual.
18. **Help/Privacy are first-class in-app docs**, not a marketing site.
19. **Invite-only join** as the household default.
20. **Play and Live share one TheaterPlayer shell.**
21. **What’s New modal** on version bump (even on `/login`).
22. **About page ships the entire CHANGELOG** into the DOM.
23. **Seerr is the member request path**; owners keep *arr.
24. **Phase 6 delight (gift queue, trust diary) stays parked.**

## 5. Benchmarks

Same category: self-hosted “what should we watch / grab next” for Plex households.

| Product | Pattern worth learning | Contrast with Projectionist |
|---|---|---|
| **Jellyseerr** | Request/approve as the household verb; Plex-like browse; quotas; mobile-first request UI | Projectionist is curator-first; Seerr is optional member path |
| **Shortlist** | Private per-user Plex Home rows (“Picked for You”) with hide-before-show labels | Projectionist keeps discovery **in its own app**, not on Plex Home |
| **Diskovarr** | Signed-in discovery portal: carousels, reason tags, requests, yearly Wrapped | Closest portal analog; Projectionist adds chat, Live, Play, MCP |

Inspiration, not templates: Jellyseerr’s request clarity for members; Shortlist’s “don’t leak rows across the house”; Diskovarr’s reason tags on every card; Vanguarr’s inspectable taste file.
